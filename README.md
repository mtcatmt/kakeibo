# 家計簿（複式簿記・PWA）

iPhoneのホーム画面に追加して使う、複式簿記の家計簿。データはiPhoneの中（IndexedDB）にだけ保存され、サーバーには送られない。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` / `style.css` | 画面の骨組みと見た目（ダークモードはiPhoneの設定に合わせて切り替わる） |
| `app.js` | 画面の動き（入力・履歴・グラフ・設定） |
| `ledger.js` | 帳簿の計算（残高・純資産・月別集計・固定費の自動作成） |
| `charts.js` | グラフの描画（SVG） |
| `sw.js` | オフラインで開くためのService Worker |
| `manifest.webmanifest` / `icons/` | ホーム画面に追加したときの名前とアイコン |
| `tests/` | `ledger.js` のテスト（`node --test tests/ledger.test.mjs`） |

## GitHub Pagesに置く手順

1. GitHubで新しいリポジトリを作る（例：`kakeibo`）。無料プランでPagesを使うには **Public** にする。公開されるのはプログラムだけで、家計のデータは含まれない。
2. リポジトリの画面で「Add file」→「Upload files」を選び、このフォルダの中身（`index.html` などのファイルと `icons` フォルダ）をドラッグして「Commit changes」。
3. 「Settings」→「Pages」で、Source を「Deploy from a branch」、Branch を `main` と `/ (root)` にして「Save」。
4. 1〜2分後に `https://<ユーザー名>.github.io/kakeibo/` で開けるようになる。

## iPhoneでの使い始め

1. 上のURLをChrome（またはSafari）で開き、共有メニューから「ホーム画面に追加」を選ぶ。
2. 以後はホーム画面のアイコンから開く。ブラウザのタブで開いた場合とはデータが別々になる。
3. 設定画面の「開始残高」で、使い始める日の現金・銀行口座・電子マネー・クレジットカード（未引き落としの利用額）・奨学金（返済あり）の残高を入れる。
4. 設定画面の「固定費」で、通信費・Claude・Amazon Primeの金額・日付・支払元を入れる。

URLの末尾に `?demo` を付けると、仮のデータで画面を確認できる（このとき入力した内容は保存されない）。

## アプリを更新したとき

`sw.js` の `CACHE` の番号を上げてからアップロードする（例：`kakeibo-v1` → `kakeibo-v2`）。番号を上げないと、iPhoneに保存された古いファイルが使われ続ける。新しい版が読み込まれると、画面下に「再読み込み」のボタンが出る。

## 仕訳の作り方

| 入力 | 借方 | 貸方 |
|---|---|---|
| 支出 | 費用の科目 | 支払元（現金・カードなど） |
| 収入 | 入金先 | 収益の科目 |
| 振替 | 移動先 | 移動元 |
| 開始残高（資産） | 資産 | 開始残高 |
| 開始残高（負債） | 開始残高 | 負債 |

- カードの引き落とし：振替で、移動元＝銀行口座、移動先＝クレジットカード。
- 貸与奨学金の受け取り：振替で、移動元＝奨学金（返済あり）、移動先＝銀行口座。
- 月別の支出は、カードを使った日の月に数える（引き落とし日は振替なので支出に含まれない）。

## NISA（クレジットカードでの積立）

| 出来事 | 入力 | 仕訳 |
|---|---|---|
| 毎月の積立 | 設定 →「固定費・積立」の「NISA積立」に金額と日付を入れる（自動入力） | 借方 NISA（投資信託） / 貸方 クレジットカード |
| 評価額の更新（月1回程度） | 設定 または グラフ画面の「評価額を更新」 | 値上がり：借方 NISA / 貸方 評価差額、値下がり：借方 評価差額 / 貸方 NISA |
| 売却 | 先に評価額を売却額に更新し、振替：NISA → 入金先 | 借方 入金先 / 貸方 NISA |

- 積立は資産の購入なので、支出には数えない。
- 「評価差額」は純資産の科目で、残高はこれまでの値上がり額の累計。収益・費用ではないので、収入と支出のグラフには影響しない。純資産の推移には評価額で反映される。
- すでに持っている分は、「開始残高」で NISA（投資信託）に今の評価額を入れる。
